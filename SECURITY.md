# Security

Report suspected vulnerabilities through GitHub's private vulnerability
reporting for this repository. Open the repository's security page and choose
**Report a vulnerability**. See [GitHub's reporting instructions](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).

Do not disclose vulnerability details in public issues or discussions. If the
private reporting button is unavailable, open an issue asking for a private
contact channel without including vulnerability details or sensitive data.

Include the affected version or commit, the component involved, steps to
reproduce with synthetic data, and the impact you observed. Test only systems
you own or have permission to test.

Do not include API keys, OAuth secrets, access tokens, cookies, or private tool
inputs and responses. Remove sensitive data from logs and screenshots before
sharing them, including in private reports.

No response or remediation deadline is guaranteed.
